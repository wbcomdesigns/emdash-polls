# What's new in 0.5.2

**Included in Free.** WB Polls has no paid version.

No new permission. Copy the kit again after you update (the command is in the install guide).

- **Delete my votes always works.** Erasing your own votes no longer counts toward the hourly vote limit, so a member who voted and changed their vote a few times can still remove their votes at once. The limit itself is 8 vote saves an hour per visitor.
- **No twin answers.** A poll with two answers that read the same (also "Same" and "same ") is refused with "Give each answer different text.", on the Polls screen and in the post editor's Poll panel.
- **Closing dates that have passed.** Open on a poll whose closing date has passed now tells you to set a later date instead of saying "Poll opened.". Saving a closing date that has already passed, or one before the opening date, is refused.
- **Polls list on a phone.** Status and Actions come right after the question, and a long question is shortened in the list (the full question shows on Edit and Results).
- **Your place in the list is kept.** Open, Close and Delete answer with the page and search you were on.
- **Find older polls in the Poll panel.** The panel lists the 25 newest polls; Find a poll by its question searches older ones.
- **Quieter install command.** The kit command no longer prints git's detached HEAD advice.
- **Fewer requests per page.** A page with an above and a below poll slot asks the site once.
- **Long words wrap.** A long unbroken word or link in an answer wraps inside the poll card.
