# What's new in 0.5.1

**Included in Free.** WB Polls has no paid version.

No new permission. Needs EmDash 1.2.0 or later.

- **The Poll panel for your writers.** Until now only site admins could use the post editor's Poll panel. Editors can now use it on any post or page, and Authors on their own. Contributors and Subscribers do not see it work.
- **Authors only reuse their own polls.** An Author's list of existing polls shows only polls they made in the panel and that no page uses now, so they never take a poll off another page or the whole site, or reopen someone else's poll. Polls made in the admin are for Editors and admins to place.
- **EmDash 1.2.0 or later.** The release now says which EmDash it needs, so an older site is told before it installs.

The Polls screen and the dashboard card stay for site admins.
