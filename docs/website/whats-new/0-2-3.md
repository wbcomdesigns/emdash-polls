# What's new in 0.2.3

**Included in Free.** WB Polls has no paid version.

A polish release from a full walk on a fresh EmDash blog site, as a site owner and as a visitor.

## For site owners

- **Pick open and close times from a calendar.** The poll form now has a date picker and a time list instead of a typed date. Times are in UTC, and the labels say so.
- **Position on the page works.** Place one slot above the content and one below, and each poll shows on the side you chose. A single slot keeps showing every poll, as before.
- **The post editor tells you which poll visitors see.** When a post shows a poll attached to all posts or the whole site, the Poll panel names it instead of saying there is none.
- **Delete asks once.** One confirm with the poll's name, no second dialog.
- **Clearer Polls screen.** A one-line intro; how guest votes are counted is now in the guides.

## For visitors

- The poll card no longer has a blank band above the question.
- Result bars use your theme's brand colour in light and dark mode.
- My votes: the sign-in prompt is a plain note, not a red error, and the spacing around the list and the delete note is even.

## For developers

- The install guide copies the two shared kit files only when the site's copy is older, so another Wbcom plugin's newer copy is never replaced.
- Copy the site kit again after updating.
