# What's new in 0.3.1

**Included in Free.** WB Polls has no paid version.

- **Guest voting needs a visitor address.** Guests vote where your hosting tells EmDash the visitor's address: on Cloudflare, or with `trustedProxyHeaders` set to a header your proxy writes itself. Elsewhere guests see a sign-in link, members vote as usual, and the Polls screen says so in one line. See [Guest voting](../getting-started/install.md#guest-voting).
- **One vote counts once.** Two votes sent at the same moment by one visitor no longer both count on a one-choice poll.
- **Set up visitor pages.** The Polls screen opens with the one command that copies the site kit for the version you installed, the addresses it adds, and a link to the install guide.
- **One-command kit copy.** `scripts/add-to-site.sh` copies the kit, keeps a newer shared Wbcom file, backs up a changed wording file, and prints the template lines with their file names.
- **The poll slot snippet works on the blog template.** The guides name `src/pages/posts/[slug].astro` and import `../../components/PollSlot.astro`.
- **Results for everyone.** A guest who cannot vote still sees the results of a poll whose results show always.
- **Dark mode buttons.** Vote buttons use your theme's own brand colours and pass 4.5:1.

Copy the site kit again after you update.
