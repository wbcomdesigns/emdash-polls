# What's new in 0.2.4

**Included in Free.** WB Polls has no paid version.

- **Readable on every light or dark choice.** A poll follows your site's light or dark setting, so it stays readable when a visitor picks light mode on a device set to dark. Themes that switch dark mode with a class are followed too.
- **New guides.** [Use cases](../getting-started/use-cases.md) and [Use it on blog posts and pages](../getting-started/posts-and-pages.md).

Copy the site kit again after you update: the shared style file `wbcom-base.css` changed.
