# What's new in 0.3.0

**Included in Free.** WB Polls has no paid version.

- **See activity at a glance.** The Polls list opens with how many polls are open and how many votes came in this week, and each poll's status is a badge.
- **Results as a chart.** Results open with a bar chart, then the totals and the full answer table. A named poll lists its voters 25 at a time.
- **A poll inside post text.** The optional This page's poll block places the page's poll in the middle of a post. Attach the poll in the post editor's Poll panel as before. It needs the trusted install described in the setup guide.
- **Safer server calls.** The shared kit file now runs server-side plugin calls inside EmDash, with no web request.

Copy the site kit again after you update.
